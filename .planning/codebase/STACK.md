# Technology Stack (Backend)

## Core
- **Language**: Java 21
- **Framework**: Spring Boot 3.3.x
- **Build Tool**: Gradle

## Persistence
- **Database**: MySQL (Connector J)
- **ORM**: Spring Data JPA, QueryDSL (for dynamic queries)
- **Migration**: Flyway
- **Cache**: Redis (Spring Data Redis)

## Communication
- **Real-time**: Spring WebSocket (STOMP)
- **Push**: Firebase Admin SDK

## Infrastructure
- **Cloud**: AWS S3 (via spring-cloud-starter-aws)
- **Logging**: Actuator, Micrometer (Prometheus)
- **Documentation**: release_notes.md, backend-context.txt
